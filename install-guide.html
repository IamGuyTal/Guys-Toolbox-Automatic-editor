Guy Tal - Toolbox לפרמייר פרו

ארגז כלים חינמי לפרמייר פרו, בעברית ובאנגלית: כתוביות, הסרת שקטים, החלפת מצלמות בפודקאסט וחילוץ רילז.

  • כתוביות: תמלול על המחשב שלכם, עורך כתוביות, והכנסה לטיימליין כ-Caption Track אמיתי
  • הסרת שקטים: חותך את הקטעים השקטים בסרטון גלם, בלי לחתוך אף מילה
  • פודקאסט: מחליף מצלמה לפי מי שמדבר (2–4 דוברים, עם שוט רחב)
  • רילז: מוצא את הקטעים הכי חזקים בפרק ובונה מכל אחד סיקוונס אנכי 9:16

דרישות

פרמייר פרוגרסה 2025 ומעלה
מחשבמק עם מעבד Apple (M1/M2/M3/M4) או Windows 10/11
מקום פנויבערך 2GB לכל שפה (מודל התמלול יורד בפעם הראשונה)

מק עם מעבד Intel עדיין לא נתמך.

התקנה

שלב 1: הורידו את התוסף

הורידו את הקובץ Guy-Tal-Toolbox-1.1.0.zxp.

שלב 2: התקינו אותו

הדרך הקלה: ZXP Installer (חינמי)
  1. הורידו והתקינו את ZXP Installer (יש גרסה למק ול-Windows).
  2. סגרו את פרמייר.
  3. פתחו את ZXP Installer וגררו לתוכו את קובץ ה-zxp.
  4. חכו להודעה שההתקנה הצליחה.

מי שהתקין גרסה קודמת (Captions) מקבל את ארגז הכלים כעדכון. המודלים שכבר הורדו נשארים.

דרך חלופית בלי תוכנה נוספת (שורת פקודה)

מי שמותקן אצלו Creative Cloud כבר יש לו את מתקין התוספים של אדובי. סגרו את פרמייר, ואז:

במק: פתחו את Terminal, הדביקו את הפקודה, הוסיפו רווח וגררו את קובץ ה-zxp לחלון. לחצו Enter.

"/Library/Application Support/Adobe/Adobe Desktop Common/RemoteComponents/UPI/UnifiedPluginInstallerAgent/UnifiedPluginInstallerAgent.app/Contents/MacOS/UnifiedPluginInstallerAgent" --install

ב-Windows: פתחו את Command Prompt, הדביקו את הפקודה, הוסיפו רווח וגררו את קובץ ה-zxp לחלון. לחצו Enter.

"C:\Program Files\Common Files\Adobe\Adobe Desktop Common\RemoteComponents\UPI\UnifiedPluginInstallerAgent\UnifiedPluginInstallerAgent.exe" /install

שלב 3: פתחו בפרמייר

בתפריט: Window ← Extensions ← Guy Tal - Toolbox. מסך הבית מציג את ארבעת הכלים.

שלב 4: הורידו את מודל התמלול (פעם אחת)

בכלי הכתוביות, בראש הפאנל תופיע ההודעה "צריך להוריד את המודל". לחצו הורד. המודל שוקל בערך 1.6GB. לעברית ולאנגלית יש מודלים נפרדים.

הכלים

כתוביות

  1. בחרו שפה, מקור (כל הסיקוונס או In → Out) וכמה מילים בכתובית, ולחצו תמלל.
  2. ערכו בפאנל: לחיצה על מילה פותחת כלים, לחיצה כפולה עורכת, לחיצה על הזמן קופצת לטיימליין, ו-⌘Z / Ctrl+Z מבטל.
  3. (לא חובה) שפר עם AI מתקן מילים שתומללו לא נכון. מילים שתוקנו מסומנות בצהוב.
  4. הכנס לפרמייר כ-Caption Track. לעיצוב, בחרו את כל הכתוביות ובחרו את ה-Track Style שלכם.

הסרת שקטים

  1. בחרו מקור והגדרות: סף שקט, שקט מינימלי, ו"אוויר" לפני ואחרי דיבור.
  2. הגנה על מילים עם Whisper מוודאת שאף מילה לא נחתכת.
  3. נתח שקטים, עברו על הרשימה, וחתוך בפרמייר.
  4. החיתוך נעשה בעותק בשם "(silence cut)". המקור לא משתנה, ובטל שינויים מוחק את העותק.

פודקאסט

  1. שייכו לכל דובר טראק מיקרופון וטראק מצלמה, ואם יש, טראק לשוט רחב.
  2. נתח מי מדבר מציג פס צבעוני של כל הפרק.
  3. ערוך בפרמייר יוצר עותק "(podcast edit)". שוטים שלא בשימוש מכובים, לא נמחקים.

רילז

  1. בחרו מקור ושפה. אם הגדרתם את כלי הפודקאסט, בחרו פוקוס: המרואיין, או כולם.
  2. מצא רילז: הפרק מתומלל וה-AI מחפש סיפורים שעומדים בפני עצמם.
  3. עברו על הרשימה ובחרו. אפשר להסיר קטע או ריל שלם.
  4. צור סיקוונסים: כל ריל נבנה בתיקייה Reels, אנכי 9:16 כשהמקור רחב.

בעיות נפוצות

לא רואים את התוסף בתפריט Extensions

סגרו את פרמייר לגמרי (⌘Q במק, Alt+F4 ב-Windows) ופתחו מחדש. אם עדיין לא מופיע, התקינו שוב את קובץ ה-zxp.

במק: הודעה ש-whisper-cli לא יכול להיפתח

פתחו System Settings ← Privacy & Security, גללו למטה ולחצו Open Anyway ליד whisper-cli.

ב-Windows: התמלול איטי

ב-Windows התמלול רץ על המעבד. בפרקים ארוכים כדאי לעבוד על קטעים עם In/Out.

ב-Windows: האנטי-וירוס חוסם

התוסף מריץ את Whisper (whisper-cli.exe) מתוך תיקיית התוסף. אם האנטי-וירוס חוסם אותו, אשרו אותו.

יש טראקים נעולים

הסרת שקטים ופודקאסט לא עובדים על טראקים נעולים. פתחו את הנעילה ונסו שוב.

הסרה

  • התוסף: ב-ZXP Installer בחרו את Guy Tal - Toolbox ולחצו Remove.
  • המודלים (בערך 3GB): מחקו את התיקייה ~/Library/Application Support/PremiereCaptions (מק) או %APPDATA%\PremiereCaptions (Windows).

English

A free Premiere Pro toolbox for Hebrew and English: captions, silence removal, podcast camera switching and reels extraction.

Install

  1. Download Guy-Tal-Toolbox-1.1.0.zxp.
  2. Quit Premiere and install it with the free ZXP Installer (drag the file in).
  3. Open Premiere and choose Window → Extensions → Guy Tal - Toolbox.
  4. In Captions, click Download next to the model status (about 1.6 GB, once per language).

The tools

  • Captions: transcribe, edit, optionally improve with AI, insert as a Caption Track.
  • Silence removal: analyse, review, cut. Works on a copy; Undo deletes it.
  • Podcast: map speakers to mic and camera tracks, analyse, edit. Works on a copy.
  • Reels: find reels, review them, create vertical sequences in a "Reels" bin.

AI

Pick Gemini (free) or Claude (paid per use). Only text is sent, never audio or video, and only when you click the button.

Troubleshooting

  • Panel missing: fully quit and reopen Premiere, or reinstall the zxp.
  • Mac blocks whisper-cli: System Settings → Privacy & Security → Open Anyway.
  • Slow on Windows: Windows runs on the CPU; work on In→Out ranges for long episodes.
  • Locked tracks: unlock them before silence removal or podcast edits.
