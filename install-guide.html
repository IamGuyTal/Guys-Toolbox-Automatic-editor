Captions לפרמייר פרו

תוסף חינמי שמייצר כתוביות אוטומטיות בעברית ובאנגלית ומכניס אותן לטיימליין כ-Caption Track אמיתי, שאפשר לערוך ולעצב.

  • תמלול על המחשב שלכם: בחינם, בלי להעלות את הסרטון לשום מקום
  • עורך כתוביות: הזזת מילים בין כתוביות, פיצול, מיזוג ותיקון טקסט
  • שיפור עם AI (לא חובה): Gemini מתקן מילים שתומללו לא נכון ומחלק לפי משמעות
  • כתוביות חיות בפרמייר: מעצבים עם ה-Track Style שלכם, ומקבלים גם קובץ SRT

English guide below ↓

דרישות

פרמייר פרוגרסה 2025 ומעלה
מחשבמק עם מעבד Apple (M1/M2/M3/M4) או Windows 10/11
מקום פנויבערך 2GB לכל שפה (המודל יורד בפעם הראשונה)

מק עם מעבד Intel עדיין לא נתמך.

התקנה

שלב 1: הורידו את התוסף

הורידו את הקובץ Captions-1.0.1.zxp.

שלב 2: התקינו אותו

הדרך הקלה: ZXP Installer (חינמי)
  1. הורידו והתקינו את ZXP Installer (יש גרסה למק ול-Windows).
  2. סגרו את פרמייר.
  3. פתחו את ZXP Installer וגררו לתוכו את הקובץ Captions-1.0.1.zxp.
  4. חכו להודעה שההתקנה הצליחה.
דרך חלופית בלי תוכנה נוספת (שורת פקודה)

מי שמותקן אצלו Creative Cloud כבר יש לו את מתקין התוספים של אדובי. סגרו את פרמייר, ואז:

במק: פתחו את Terminal, הדביקו את הפקודה, הוסיפו רווח, וגררו את קובץ ה-zxp לחלון. לחצו Enter.

"/Library/Application Support/Adobe/Adobe Desktop Common/RemoteComponents/UPI/UnifiedPluginInstallerAgent/UnifiedPluginInstallerAgent.app/Contents/MacOS/UnifiedPluginInstallerAgent" --install

ב-Windows: פתחו את Command Prompt, הדביקו את הפקודה, הוסיפו רווח, וגררו את קובץ ה-zxp לחלון. לחצו Enter.

"C:\Program Files\Common Files\Adobe\Adobe Desktop Common\RemoteComponents\UPI\UnifiedPluginInstallerAgent\UnifiedPluginInstallerAgent.exe" /install

שלב 3: פתחו בפרמייר

פתחו את פרמייר ובחרו בתפריט Window ← Extensions ← Captions.

שלב 4: הורידו את מודל התמלול (פעם אחת)

בראש הפאנל תופיע ההודעה "צריך להוריד את המודל". לחצו הורד. המודל שוקל בערך 1.6GB וההורדה לוקחת כמה דקות. לעברית ולאנגלית יש מודלים נפרדים, והם יורדים לפי השפה שבוחרים.

איך משתמשים

  1. בחרו שפה, מקור (כל הסיקוונס, או רק בין In ל-Out שסימנתם), וכמה מילים בכתובית.
  2. לחצו תמלל.
  3. ערכו בפאנל:
    • לחיצה על מילה בוחרת אותה ופותחת כלים: העברה לכתובית הקודמת או הבאה, פיצול, עריכה ומחיקה
    • לחיצה כפולה פותחת את המילה לעריכה
    • לחיצה על הזמן קופצת לנקודה הזו בטיימליין
    • בטל ↶ (או ⌘Z / Ctrl+Z) מבטל את הפעולה האחרונה
  4. (לא חובה) לחצו שפר עם AI. מילים שתוקנו יסומנו בצהוב.
  5. לחצו הכנס לפרמייר כ-Caption Track.
  6. לעיצוב: בחרו את כל הכתוביות בטראק, ובחלון Properties או Essential Graphics בחרו את ה-Track Style שלכם.

שיפור עם AI: מפתח Gemini חינמי (לא חובה)

  1. בפאנל, לחצו "קבל מפתח" ליד "מפתח Gemini" (או היכנסו ל-aistudio.google.com/apikey).
  2. התחברו עם חשבון גוגל ולחצו Create API key.
  3. העתיקו את המפתח (מתחיל ב-AIza) והדביקו בשדה בפאנל.
המפתח נשמר רק אצלכם. בתוכנית החינמית Google עשויה להשתמש בטקסט שנשלח כדי לשפר את המודלים שלה. נשלח רק הטקסט של הכתוביות, ורק כשלוחצים על הכפתור.
לפעמים Gemini עמוס. אם מופיעה הודעה שלקח לו יותר מדי זמן, לחצו שוב.

בעיות נפוצות

לא רואים את Captions בתפריט Extensions

סגרו את פרמייר לגמרי (⌘Q במק, Alt+F4 ב-Windows) ופתחו מחדש. אם עדיין לא מופיע, התקינו שוב את קובץ ה-zxp.

במק: הודעה ש-whisper-cli לא יכול להיפתח

פתחו System Settings ← Privacy & Security, גללו למטה ולחצו Open Anyway ליד whisper-cli. נסו לתמלל שוב.

ב-Windows: התמלול איטי

ב-Windows התמלול רץ על המעבד ולא על הכרטיס הגרפי, אז הוא לוקח יותר זמן, תלוי במחשב. בסרטונים ארוכים כדאי לתמלל קטעים עם In/Out.

ב-Windows: האנטי-וירוס חוסם

התוסף מריץ את Whisper (whisper-cli.exe) מתוך תיקיית התוסף. אם האנטי-וירוס חוסם אותו, אשרו אותו.

הכתוביות לא מדויקות

ודאו שבחרתם את השפה הנכונה לפני התמלול. מודל העברית מיועד לעברית בלבד.

הסרה

  • התוסף: ב-ZXP Installer בחרו את Captions ולחצו Remove. או מחקו את התיקייה Captions מתוך:
    • מק: /Library/Application Support/Adobe/CEP/extensions/
    • Windows: C:\Program Files (x86)\Common Files\Adobe\CEP\extensions\
  • המודלים (בערך 3GB): מחקו את התיקייה:
    • מק: ~/Library/Application Support/PremiereCaptions
    • Windows: %APPDATA%\PremiereCaptions

פרטיות

  • האודיו מתומלל על המחשב שלכם ולא נשלח לשום מקום.
  • אם לוחצים "שפר עם AI", רק הטקסט של הכתוביות נשלח ל-Google Gemini.

קרדיטים

  • whisper.cpp (רישיון MIT)
  • OpenAI Whisper large-v3-turbo (רישיון MIT)
  • מודל העברית של ivrit.ai (רישיון Apache 2.0)

English

A free Premiere Pro extension that auto-generates Hebrew and English captions and adds them to your timeline as a real, editable Caption Track.

Requirements

Premiere Pro 2025 or newer. Mac with Apple Silicon, or Windows 10/11 (Intel Macs are not supported yet). About 2 GB free per language.

Install

  1. Download Captions-1.0.1.zxp.
  2. Quit Premiere and install with the free ZXP Installer (drag the file in).
  3. Open Premiere and choose Window → Extensions → Captions.
  4. Click Download next to the model status (about 1.6 GB, once per language).

Use

Choose language, source (whole sequence or In→Out) and words per caption, then Transcribe, edit, optionally Improve with AI, and Insert into Premiere as Caption Track.

Troubleshooting

  • Panel missing: fully quit and reopen Premiere, or reinstall the zxp.
  • Mac blocks whisper-cli: System Settings → Privacy & Security → Open Anyway.
  • Slow on Windows: Windows runs on the CPU; transcribe In→Out ranges for long videos.

Privacy

Audio is transcribed locally and never uploaded. Only caption text is sent to Google Gemini, and only when you click "Improve with AI".
